# Clean Engineering Foundations Skill

Use this skill to maintain pristine, minimal complexity code with zero placeholders or dead code.

## Rules & Standards
1. **No Placeholders**: Never write `// TODO`, `/* implement later */`, or mock stub omissions.
2. **Minimal Accidental Complexity**: Choose the simplest abstraction that solves the complete problem.
3. **Explicit Typing**: Enforce strict TypeScript and Pydantic schemas across all boundaries.
