# UI/UX Design Taste & Visual Architecture Skill

Use this skill to design distinct, premium interfaces that avoid generic AI-generated aesthetics.

## Design Principles & Rules

### 1. Spatial Hierarchy & Distinctive Rhythm
- **Rhythm**: Avoid uniform, repetitive card grids. Mix hero metric callouts, high-density data tables, and asymmetrical feature splits.
- **Micro-Borders & Depth**: Use subtle multi-layered borders: `border border-white/[0.08] bg-slate-900/60 backdrop-blur-md shadow-2xl`.
- **Gradients**: Avoid rainbow AI gradients. Use disciplined monochromatic or dual-tone glows (e.g., Deep Slate, Electric Cyan, Solar Amber).

### 2. Typography & Contrast Discipline
- **Font Pairing**: Crisp modern sans-serif (Inter, Geist, SF Pro) with tabular numbers (`font-mono tabular-nums`) for financial & operational metrics.
- **Contrast Ratios**: Strict WCAG AA compliance (4.5:1 for body text, 3:1 for large headers).
- **Status Indicators**: Use semantic status chips with subtle pulses for live/active states.
